# Shopee Crypto Checkout - Concept Prototype

Clickable concept prototype by Transfero showing how Transfero Checkout, consumed via its Partner API, could appear as a native crypto payment method inside a marketplace checkout, with no redirect and no new tab.

**This is not a Shopee product and has no affiliation with Shopee.** All amounts, wallet addresses and QR codes are fictitious; the QR code is not scannable.

## How to view

Open `index.html` in any browser. The left panel jumps between journey steps and simulates payment and expiration; the right panel shows which Checkout API call backs each screen.

## Journey

Cart, checkout, payment method (crypto: USDT, USDC or BRZ on Polygon), first-use welcome, payment (QR code, copy-and-paste code, 5-minute quote), automatic detection, approval and expiration.

API reference: https://cryptocheckout.transfero.app/docs/introduction
