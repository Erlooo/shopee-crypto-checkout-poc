    Behind the screen: Transfero Checkout API

    Base: /api/v1/partner-api. Every call uses a Bearer JWT from POST /auth/token (headers x-partner-id and x-partner-secret). Shopee calls the API from its own backend and renders everything in its own front end: Transfero never shows up as a page, only as the payment processor.
